# 2025-02-24
how can I use the "sed" command to append text to a line?

## Response:

There are several ways to use `sed` to append text to a line. Here are some common approaches:

1. Append text after a specific line number:
```bash
sed '2 s/$/ appended text/' file.txt
```

2. Append text after a line matching a pattern:
```bash
sed '/pattern/s/$/ appended text/' file.txt
```

3. Append text after every line:
```bash
sed 's/$/ appended text/' file.txt
```

Examples:

```bash
# Append "END" after line 3
sed '3 s/$/ END/' file.txt

# Append "DONE" after lines containing "Hello"
sed '/Hello/s/$/ DONE/' file.txt

# Append comma after every line
sed 's/$/,/' file.txt
```

Important notes:
- To save changes to the file, use the `-i` option:
  ```bash
  sed -i '3 s/$/ END/' file.txt
  ```

- On macOS, use `-i ''`:
  ```bash
  sed -i '' '3 s/$/ END/' file.txt
  ```

- `$` represents the end of the line in the substitution pattern
- The space before "appended text" is included in the output

You can also use an alternative syntax with the `a` command:
```bash
# Append text on a new line after line 3
sed '3a\appended text' file.txt

# Append text on a new line after matching pattern
sed '/pattern/a\appended text' file.txt
```
